# 技术架构设计

## 1. 技术栈选型

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 语言 | C# | 静态类型、Windows 桌面开发一等公民、单文件部署成熟 |
| UI 框架 | WinForms | 轻量、原生 Win32 封装完善，悬浮窗/穿透/托盘/通知均有成熟 API |
| 目标框架 | .NET Framework 4.8 | **Windows 10/11 系统内置**，程序零运行时依赖，exe 仅 1~2 MB，双击即用 |
| 编译方式 | .NET 8 SDK + SDK 风格 csproj | 现代项目结构、`dotnet build` 一键编译；通过 NuGet 引用 `Microsoft.NETFramework.ReferenceAssemblies` 编译 net48，无需安装旧版 targeting pack |
| 图表 | 自绘 GDI+ 柱状图 | 每日消费柱状图需求简单（柱形+坐标+网格），自绘零依赖、体积最小 |
| 数据存储 | JSON 文件（`Documents\QuotaMonitor\`） | **用户已确认**：数据存在「我的文档」，普通用户可直观查看、手动备份 |
| 密钥保护 | Windows DPAPI（`ProtectedData`） | 系统级加密，无需自定义加密算法，无需口令 |
| 安装包 | Inno Setup 脚本编译 | 免费、脚本化、可生成桌面/开始菜单快捷方式，支持开机自启注册 |
| 自动更新 | 无（GitHub Releases 手动分发） | 个人小范围使用，版本迭代手动分发安装包 |

**否决的方案**：Electron（>100MB 体积）、Python+PyInstaller（体积大、启动慢）、Tauri（需 Rust 工具链，构建复杂）、.NET 8 自包含（60MB+，违背小巧原则）。

## 2. 额度数据来源

### 2.1 DeepSeek 余额（官方公开接口）

```
GET https://api.deepseek.com/user/balance
Authorization: Bearer <API Key>
```

响应示例：

```json
{
  "is_available": true,
  "balance_infos": [
    { "currency": "CNY", "total_balance": "110.00",
      "granted_balance": "10.00", "topped_up_balance": "100.00" }
  ]
}
```

- 取 `balance_infos` 中 `currency == "CNY"` 项的 `total_balance`；**只显示人民币**（用户已确认），界面统一使用 ¥ 符号
- 认证失败（401 / 40002 / 40003）→ 判定为「异常」状态，悬浮窗显示橙色
- 接口返回 `is_available=false` → 判定为「账户停用」状态，悬浮窗与统计面板同步展示
- 429 限流（`BalanceQueryException.Kind`）单独分类，提示「限流」而非笼统报错
- 该接口无需登录 Cookie，仅凭 API Key，安全且稳定

### 2.2 OpenCode Go 套餐（官方接口）

`OpenCodeGoClient` 调用 OpenCode Go 官方接口查询订阅套餐余量，返回**5 小时 / 周 / 月**三个时间窗口的额度数据（总额度、已用、剩余、重置时间），供套餐模式悬浮窗展示。

健壮性处理：

- **百分比归一化**：接口返回的剩余/已用百分比异常时，按总额度与已用额度重新计算，避免展示越界值
- **auth.json 回退**：密钥配置为空时回退读取 opencode 的 `auth.json` 本地登录凭证，未配置也能展示已登录套餐
- 429 限流同样单独分类提示

## 4. 核心设计

### 4.1 状态机（BalanceMonitor）

```
                 ┌──────────────┐
    ┌───────────▶│   Normal     │◀─────────────┐
    │            │  (绿色)      │              │
    │            └──────┬───────┘              │
    │  余额 < 阈值       │    余额 ≥ 阈值        │
    │                   ▼                      │
    │            ┌──────────────┐              │
    │            │   Low        │───告警触发───▶│
    │            │  (红色)      │    (仅一次)    │
    │            └──────┬───────┘              │
    │                   │                      │
    │  查询异常          ▼                      │
    └────────────┌──────────────┐              │
                 │   Error      │───(余额保持)──┘
                 │  (橙色+⚠)    │
                 └──────────────┘
```

- 每次成功查询后写入历史记录（相同余额自动去重）
- 消费突增判定：今日消费 > 近 7 天日均 × 3（历史记录中相邻两次余额之差求和）
- Go 套餐走独立的 `SubscriptionMonitor` 状态机（成功 / 失败），数据同样按刷新间隔轮询

### 4.2 悬浮窗

- `FormBorderStyle=None` + `WS_EX_TOPMOST`（置顶）、`WS_EX_TRANSPARENT`（点击穿透）、`WS_EX_TOOLWINDOW`（不占任务栏）
- 拖动：捕获左键按下记录偏移，移动时更新 Location，松手后持久化
- 两档亮度：鼠标进入/离开时调整 `Opacity` 与背景色
- 双模式：余额模式显示 DeepSeek 余额；套餐模式显示 Go 套餐余量（5 小时/周/月，单击循环切换窗口），右键菜单「切换到 Go 套餐 / 切换到余额」切换
- 颜色：绿 `#2E9E4F` / 红 `#D64545` / 橙 `#E8930C`，色弱友好加深字色

### 4.3 刷新与并发

- 刷新间隔 6 档：5 秒 / 15 秒 / 30 秒 / 1 分钟 / 1 分 30 秒 / 2 分钟（余额与套餐共用同一刷新节奏）
- 每次刷新串行执行，前一请求未返回时跳过本轮（防堆积）；`CancellationToken` 支持退出时中断
- 网络异常指数退避：连续失败后拉长间隔至 30s，成功即恢复

### 4.4 数据模型

```json
// 余额记录.json
{ "records": [ { "time": "2026-08-05 18:30:00", "balance": 123.45 } ] }
```

**已确认的默认设置**：预警阈值默认 ¥10；币种仅人民币。

- 记录仅存「余额+时间」，变动额由相邻记录计算，避免冗余
- 文件 ≤ 5000 条时截断（保留最近），控制体积

### 4.5 通知

- 默认托盘气泡通知（`NotifyIcon.ShowBalloonTip`），零依赖
- 通知开关统一由设置控制，余额不足告警与消费突增告警可分别开关

### 4.6 主题（跟随系统深浅色 + Win11 配色）

- `SystemTheme` 通过 `SystemEvents.UserPreferenceChanged`（Category=Color）监听系统主题变化，触发 `Changed` 事件
- 各窗口（设置 / 统计）订阅事件后调用 `ApplyTheme()`：重设背景/前景/面板/分隔线/输入框等色值，并遍历子控件按角色重设 Label 颜色、重设 DWM 标题栏
- 自绘控件（`NavSidebar` / `ModernSlider` / `ModernCheckBox` / `ModernComboBox` / `CardButton` / 进度条）均提供 `ApplyTheme(bool dark)`：`_dark` 从只读改为可变 + 重绘
- 配色遵循 Win11 规范：深色窗口 `#202020` / 表面 `#2D2D2D` / 输入框 `#323232`；浅色窗口 `#FFFFFF` / 表面 `#F3F3F3`；强调色 `#0067C0`
- 悬浮窗为深色半透明自绘设计，天然跨主题，不随系统切换

### 4.7 UI 调试模式（设置开关驱动）

- 设置 → 其他 → 「界面调试模式」（`Config.DebugMode`）：开启后各页面挂载 `DebugProbe`（唯一标识 + Tooltip + 悬停高亮），并导出控件树快照到 `%TEMP%\opencode\`
- 设置页勾选时**即时生效**：已打开的统计页通过 `AttachDebugProbe()` 补挂，无需重启
- 调试能力常驻代码库、由单一设置开关掌控，用完即关，参见 `docs/UI元素定位调试通用方案.md`

## 5. 安全与隐私

- API Key 仅保存在本机，DPAPI 加密后落盘，不上传任何第三方
- 无任何遥测、无自动更新、无外部 CDN
- 日志不含 API Key（查询时只记录状态码与耗时）

## 6. 兼容性

- 目标：Windows 10 / 11（x64 优先，x86 兼容）
- .NET Framework 4.8 系统内置，无需安装任何运行时
