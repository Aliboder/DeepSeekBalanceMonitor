# 构建与打包

## 环境要求

- .NET 8 SDK（本机已安装至 `%USERPROFILE%\.dotnet`，或全局安装）
- Windows 10 / 11
- 打包需要 [Inno Setup 6](https://jrsoftware.org/isinfo.php)（编译安装脚本用）

## 编译（Release）

```bash
export PATH="$PATH:$HOME/.dotnet"
dotnet build src/QuotaMonitor/QuotaMonitor.csproj -c Release
```

产物：`src/QuotaMonitor/bin/Release/net48/QuotaMonitor.exe`

> 目标框架为 .NET Framework 4.8：**exe 单文件，无任何依赖**，Windows 10/11 可直接运行。

## 本地打包（推荐）

本地发布用根目录 `installer.iss`（引用 `publish\Release` 下的产物）：

```powershell
$dotnet = "C:\Users\Aliboder\.dotnet\dotnet.exe"

# 1. 发布（win-x64，含 exe.config）
& $dotnet publish "src\QuotaMonitor\QuotaMonitor.csproj" -c Release -r win-x64 --self-contained false -o "publish\Release"

# 2. 编译安装包
& "C:\Users\Aliboder\AppData\Local\Programs\Inno Setup 6\ISCC.exe" "installer.iss"
```

产物：`installer\QuotaMonitor-Setup-v<版本>.exe`

安装包行为：

- 安装到 `%ProgramFiles%\QuotaMonitor\`（`PrivilegesRequired=lowest`，个人工具无需管理员权限）
- 创建桌面快捷方式与开始菜单项
- 卸载时保留用户数据目录（`文档\QuotaMonitor\`），卸载不影响历史记录
- 用户数据目录升级后可从旧位置（`文档\DeepSeek余额监控\`）自动迁移

## CI 自动构建

`.github/workflows/build.yml` 在推送 `master` 或 `v*` 标签时自动执行：

1. `dotnet build src/QuotaMonitor/QuotaMonitor.csproj -c Release`
2. 运行 `tools/CoreTests` 核心测试
3. 用 `installer/installer.iss`（引用 `bin\Release\net48`）编译安装包
4. 上传安装包为 Artifact；推 `v*` 标签时自动发布 GitHub Release

## 分发方式

- 通过 [GitHub Releases](https://github.com/Aliboder/QuotaMonitor/releases) 发布安装包
- 也可通过私人渠道（微信/网盘）直接分发 exe

## 常见问题

- **构建报 MSB4062 / 找不到 Reference Assemblies**：NuGet 自动还原 `Microsoft.NETFramework.ReferenceAssemblies` 包，需要网络；离线环境请先 `dotnet restore` 一次。
- **双击 exe 提示需要 .NET Framework**：说明系统为 Windows 7 等旧系统，本软件仅支持 Windows 10/11。
- **ISCC 找不到**：本地 Inno Setup 默认装在 `C:\Users\<用户>\AppData\Local\Programs\Inno Setup 6\`（当前用户安装），CI 用 choco 安装到 Program Files。
