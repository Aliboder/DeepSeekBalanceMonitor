# 构建与打包

## 环境要求

- .NET 8 SDK（本机已安装至 `%USERPROFILE%\.dotnet`，或全局安装）
- Windows 10 / 11
- 打包需要 [Inno Setup 6](https://jrsoftware.org/isinfo.php)（编译安装脚本用）

## 编译（Release）

```bash
export PATH="$PATH:$HOME/.dotnet"
dotnet build src/DeepSeekBalanceMonitor/DeepSeekBalanceMonitor.csproj -c Release
```

产物：`src/DeepSeekBalanceMonitor/bin/Release/DeepSeekBalanceMonitor.exe`

> 目标框架为 .NET Framework 4.8：**exe 单文件，无任何依赖**，Windows 10/11 可直接运行。

## 打包安装包

1. 用 Inno Setup 打开 `installer/installer.iss`，或命令行编译：
   ```
   ISCC.exe installer/installer.iss
   ```
2. 产物：`installer/Output/DeepSeekBalanceMonitor-Setup.exe`

安装包行为：

- 安装到 `%LOCALAPPDATA%\DeepSeekBalanceMonitor\`（个人工具，无需管理员权限）
- 创建桌面快捷方式与开始菜单项
- 卸载时保留用户数据目录（`%LOCALAPPDATA%\DeepSeekBalanceMonitor\Data`）

## 分发方式

仅通过私人渠道（微信/网盘）发给朋友，**不上传任何公众平台**。

## 常见问题

- **构建报 MSB4062 / 找不到 Reference Assemblies**：NuGet 自动还原 `Microsoft.NETFramework.ReferenceAssemblies` 包，需要网络；离线环境请先 `dotnet restore` 一次。
- **双击 exe 提示需要 .NET Framework**：说明系统为 Windows 7 等旧系统，本软件仅支持 Windows 10/11。
