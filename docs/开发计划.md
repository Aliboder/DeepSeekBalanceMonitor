# 开发计划

## 里程碑

| 阶段 | 内容 | 验收标准 |
|------|------|----------|
| M1 项目骨架 | csproj + 入口 + 配置/日志/存储基础 | `dotnet build` 通过，程序启动后常驻托盘 |
| M2 核心数据链 | API 客户端 + 轮询调度 + 历史存储 | 日志可见余额查询成功/失败记录 |
| M3 悬浮窗 | 悬浮窗 UI + 状态颜色 + 拖动记忆 + 穿透/置顶 | 窗口显示实时余额，交互符合需求 |
| M4 托盘与隐藏 | 托盘图标/菜单 + 定时隐藏 + 通知 | 托盘操作齐全，隐藏自动恢复 |
| M5 告警引擎 | 阈值告警 + 消费突增告警 | 手动造数可触发两类通知 |
| M6 统计面板 | 摘要 + 走势图 + 历史表 | 数据与真实余额一致，图表达标 |
| M7 设置窗口 | 全部设置项 + 密钥管理 + 开机自启 | 改动即时生效 |
| M8 打包发布 | Inno Setup 安装包 | 全新机器双击安装即可使用 |

## 开发顺序说明

1. M1→M2 先打通「查询→存储」数据链，再逐层向上做 UI，保证每步可验证。
2. 所有 UI 交互遵循需求文档「功能说明.md」，以其为唯一需求来源。
3. 每个里程碑完成后进行一次自测（模拟网络失败、余额变化场景）。

## 测试要点（人工冒烟）

- 无密钥时悬浮窗橙色 + 提示错误原因
- 错误密钥 → 认证失败橙色态，连续失败次数在托盘气泡显示
- 阈值切换：余额从高于到低于阈值 → 弹一次通知；恢复后再低于 → 再次触发
- 拖动悬浮窗后重启 → 位置复原
- 点击穿透开启后点击测试
- 刷新间隔改动即时生效
- 统计面板在深色/浅色系统主题下显示正常
- 开机自启注册后注册表检查
