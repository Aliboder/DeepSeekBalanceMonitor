# QuotaMonitor（AI 额度监控）

> 一个常驻桌面角落的 Windows 小工具，帮你**随时盯住 AI API 的额度**——余额还剩多少、还能用多久、什么时候该充值，一目了然。

## 它能做什么

- **桌面悬浮窗**：始终置顶显示当前额度，一抬眼就能看到。颜色随状态变化：🟢 正常 / 🔴 余额不足 / 🟠 查询出错
- **双模式监控**：同时支持 DeepSeek 账户余额 和 OpenCode Go 套餐余量（5 小时 / 周 / 月三个窗口），单击悬浮窗即可循环切换
- **智能提醒**：余额低于预警线时通知一次；今日消费异常突增（超近 7 天日均 3 倍）时提醒排查
- **消费记录**：自动记录每次余额变化，统计面板展示近 14 天每日消费柱状图（悬停看明细）与套餐用量进度
- **跟随系统主题**：设置窗口与统计面板自动适配 Windows 深色/浅色主题，切换无需重启
- **轻量安静**：常驻系统托盘，不占任务栏；悬浮窗可调透明度、可锁定（点击穿透）、可定时隐藏，不打扰工作

## 快速开始（3 步）

1. **下载安装**：从 [GitHub Releases](https://github.com/Aliboder/QuotaMonitor/releases) 下载 `QuotaMonitor-Setup-v*.exe`，双击按提示完成安装（Windows 10/11 自带运行环境，无需额外安装任何东西）。
2. **填写密钥**：右键桌面悬浮窗 → **设置** → **密钥**，粘贴你的 API Key，点「测试」验证后点「应用」。
   - DeepSeek 密钥：登录 [platform.deepseek.com](https://platform.deepseek.com) → API Keys 页面创建
   - OpenCode Go 密钥：在 [opencode.ai](https://opencode.ai) 订阅页面获取（不用 Go 套餐可留空）
3. **完成**：回到桌面即可看到实时额度。悬浮窗可以拖到任意位置，下次启动自动复原。

> 额度数据只来自官方接口，只使用你自己的密钥查询，**不会上传任何数据到第三方**。

## 日常使用

| 操作 | 作用 |
|------|------|
| 拖动悬浮窗 | 移动位置（自动记住） |
| 左键单击悬浮窗 | 套餐模式下循环切换 5 小时 / 周 / 月窗口 |
| 双击悬浮窗 | 打开统计面板 |
| 右键悬浮窗 / 托盘图标 | 菜单：切换模式、设置、隐藏、复位、锁定、退出 |
| 单击托盘图标 | 打开统计面板 |
| 右键悬浮窗 → 隐藏 | 让悬浮窗暂时消失（5 分钟 / 30 分钟 / 3 小时 / 自定义），到点自动恢复 |

**退出软件**：只有一条路——右键托盘图标 → **退出**。关闭窗口不会退出程序，它常驻托盘。

## 数据存在哪

所有数据存放在 `文档\QuotaMonitor\`（旧版数据目录 `文档\DeepSeek余额监控\` 会在升级后自动迁移，历史记录不丢）：

| 文件 | 内容 |
|------|------|
| `设置.json` | 你的设置（API 密钥使用 Windows 系统级加密存储） |
| `余额记录.json` | 余额变化历史 |
| `日志\` | 运行日志（自动保留最近若干份） |

## 常见问题

**悬浮窗颜色变红了/橙了？**
红 = 余额低于预警阈值（设置 → 提醒里可调整）；橙 = 查询失败（如网络不通或密钥失效），此时显示的是最后一次成功获取的额度。

**忘了密钥在哪改？**
右键悬浮窗 → 设置 → 密钥，两个密钥分别对应 DeepSeek 和 Go 套餐，支持「测试」验证、「显示」明文查看、「清空」停止查询。

**悬浮窗想更隐蔽一些？**
设置 → 显示：可调整体透明度、鼠标移开后的暗度；「锁定」开启后鼠标点击会直接穿透悬浮窗。

**想要开机自动启动？**
设置 → 其他 → 勾选「开机自动启动」。

**卸载后数据会残留吗？**
卸载只删除程序文件；`文档\QuotaMonitor\` 下的设置与历史数据会保留，如需彻底删除请手动清理该文件夹。
